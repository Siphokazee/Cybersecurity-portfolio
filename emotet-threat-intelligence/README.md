# Emotet Malware and Threat Intelligence Analysis

## Project Overview

This project documents a threat intelligence investigation focused on Emotet malware. The objective was to examine indicators of compromise (IOCs), investigate suspicious file hashes and analyse available malware behaviour to understand potential security threats.

## Tools and Technologies

- **VirusTotal** – File hash analysis and threat intelligence
- **Malware sandbox analysis** – Examination of reported malware behaviour
- **Threat intelligence research** – Investigation of indicators of compromise

## Investigation Activities

- Investigated file hashes associated with suspected malicious activity.
- Reviewed threat intelligence findings to assess malware detection and reputation.
- Examined sandbox analysis results to understand potentially malicious behaviour.
- Documented indicators of compromise, investigation findings and defensive recommendations.

## Skills Demonstrated

Malware investigation, file hash analysis, threat intelligence, IOC analysis, security research and technical reporting.

## Report

The Emotet IOC Analysis Report provides supporting evidence, investigation findings and defensive recommendations.
