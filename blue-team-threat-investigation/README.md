# Blue Team Threat Investigation

## Project Overview

This project documents a Blue Team cybersecurity investigation conducted as part of a hackathon. The objective was to analyse suspicious network activity, investigate potential indicators of compromise (IOCs) and understand how threat intelligence can support security investigations.

The investigation involved examining network traffic, researching suspicious IP addresses and analysing potential malicious activity. Findings were mapped to the **MITRE ATT&CK framework** to understand the tactics and techniques associated with the observed and suspected behaviour.

## Tools and Technologies

- **Wireshark** – Network traffic and PCAP analysis
- **VirusTotal and AbuseIPDB** – IP reputation and threat intelligence research
- **MITRE ATT&CK** – Mapping adversary tactics and techniques

## Investigation Activities

- Examined network traffic to identify suspicious connections and activity.
- Investigated IP addresses using publicly available threat intelligence sources.
- Documented indicators of compromise and assessed potential security risks.
- Mapped relevant findings to MITRE ATT&CK tactics and techniques.
- Prepared a technical report outlining the investigation, supporting evidence and recommendations.

## Skills Demonstrated

Network traffic analysis, threat intelligence, IOC investigation, security documentation and MITRE ATT&CK mapping.
