# Red Team Web Application Security Assessment

## Project Overview

This project documents a Red Team security assessment conducted against a simulated web application during a cybersecurity challenge.

The objective was to identify security vulnerabilities, assess their potential impact and document findings with supporting evidence and remediation recommendations.

## Tools and Technologies

- **Burp Suite** – HTTP request inspection and manipulation
- **Web browser developer tools** – Application inspection
- **Manual security testing** – Authentication, access control and input validation

## Assessment Activities

- Tested authentication mechanisms and identified an SQL injection vulnerability that allowed authentication bypass.
- Investigated weaknesses in password reset functionality and username enumeration.
- Identified unauthorised access to application notes through insecure access controls.
- Reviewed session cookie security and unencrypted HTTP communication.
- Documented vulnerabilities, their potential impact and recommended remediation measures.

## Skills Demonstrated

Web application penetration testing, vulnerability assessment, authentication testing, access control testing, HTTP analysis and technical security reporting.

## Report

The security assessment report, including technical findings, supporting evidence and remediation recommendations, will be added to this repository.
